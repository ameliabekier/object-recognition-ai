# Object Recognition AI

## Opis projektu

Projekt poświęcony rozpoznawaniu przedmiotów w czasie rzeczywistym z wykorzystaniem sztucznej inteligencji i technik widzenia komputerowego (Computer Vision).

Celem projektu jest sprawdzenie, w jaki sposób model AI analizuje obraz z kamery, identyfikuje obiekty i prezentuje wyniki detekcji.

## Technologie

- Python
- YOLO
- Computer Vision
- OpenCV

## Jak działa projekt?

Aplikacja analizuje obraz z kamery i wykorzystuje model detekcji obiektów do rozpoznawania elementów widocznych w kadrze. Wyniki mogą być prezentowane na obrazie wraz z oznaczeniami wykrytych obiektów.

## Cel projektu

- Poznanie praktycznych zastosowań sztucznej inteligencji.
- Nauka rozpoznawania obiektów na obrazach.
- Rozwijanie umiejętności programowania w Pythonie.
- Eksperymentowanie z modelami Computer Vision.

## Project description

A real-time object recognition project using artificial intelligence and computer vision techniques.

The goal is to explore how an AI model analyzes camera input, detects objects and presents detection results.
